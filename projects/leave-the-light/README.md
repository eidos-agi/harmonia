# Leave the Light

Working set for Harmonia. The arrangement is [leave-the-light.json](leave-the-light.json). The format is `AGDAW_JSON_V6`.

Two audio tracks start together at the beginning of the arrangement, so either one can be soloed.

1. Leave the Light. `audio/leave-the-light.wav`. 44.1 kHz, stereo, 16-bit, 6,412,184 frames (145.401 seconds).
2. Leave the Light (Super Extended). `audio/leave-the-light-super-extended.wav`. 48 kHz, stereo, 16-bit, 15,858,414 frames (330.384 seconds). The project rate is 44.1 kHz, so this clip is 14,569,918 samples long on the timeline. That keeps the duration. It does not time-stretch the recording.

Warp mode is bypass. Playback ratio is 1.

The tempo in the file is 120 and the meter is 4/4. Those are the engine defaults. They are not a measured tempo of this song. There is no key.

The recordings are not in this repository. Put the two wav files at the paths above before opening the set. A checkout without those files still opens the tracks. The clips have no audio until the wavs are there.
